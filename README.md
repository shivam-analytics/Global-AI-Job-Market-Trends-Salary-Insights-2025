# Global AI Job Market Trends & Salary Insights 2025

## 📌 Project Overview

This project analyzes global AI job market trends and salary insights for 2025. It explores AI-related job roles, salary distributions, experience levels, employment locations, and in-demand skills.

The project presents data-driven insights through dashboards to help understand the evolving artificial intelligence job market.

## 🎯 Objectives

- Analyze salaries across AI job roles.
- Explore global AI employment trends.
- Compare salaries by experience level and location.
- Identify in-demand AI skills and technologies.
- Visualize key findings using interactive dashboards.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Data Analysis
- Data Visualization
- Jupyter Notebook / Google Colab
